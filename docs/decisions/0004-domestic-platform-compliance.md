# ADR 0004：国内平台合规接入边界

## 状态

Accepted

## 背景

终局 Milestone 4 要覆盖微博、B站、知乎、微信公众号、小红书、抖音、快手等中文互联网信号。
这些平台的开放能力、审核机制、授权范围和反爬规则差异很大，不能把“覆盖平台”理解为默认抓取。

## 决策

国内平台在当前阶段只落地合规能力矩阵和人工补录闭环：

- 官方开放平台或自有账号授权：标记为 `official_auth_required`，等待用户配置合法凭证后再扩展具体 Connector。
- 无稳定官方读取能力的平台：标记为 `manual_only`，只能通过人工链接补录进入 `RawItem`。
- 所有人工补录都记录平台标签、来源名和原始链接，继续进入 `RawItem -> EventCandidate -> EventCluster -> Evidence` 链路。

## 禁止路径

- Cookie 抓取。
- 登录态模拟。
- 验证码处理。
- 私有页面抓取。
- 反爬绕过。
- 全量评论舆情或情感分析。

## 影响

正面影响：

- 产品上能清楚说明国内平台为什么不能直接自动化。
- 受限内容仍然可以通过人工证据进入统一情报链路。
- 后续真正接入官方 API 时已有平台级合规边界和 UI 入口。

约束：

- 本阶段不新增国内平台真实 Connector。
- 任何后续官方 API Connector 都必须新增或更新 ADR，并补齐凭证、限流、失败降级和测试。
