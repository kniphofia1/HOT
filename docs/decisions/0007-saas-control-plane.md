# ADR 0007：SaaS 商业化控制平面

## 状态

Accepted

## 背景

Milestone 8 要进入 SaaS 商业化阶段，包括多租户、组织管理、角色权限、套餐计费、配额、任务队列、监控告警、审计和数据隔离。
真实登录、支付扣费、生产队列和云监控都需要外部系统，不应在没有部署边界时硬接。

## 决策

当前实现 SaaS 控制平面：

- 组织、组织成员、角色。
- 套餐、订阅、配额用量。
- 任务队列记录。
- 监控告警规则。
- 租户数据归属表。
- SaaS 审计日志。

真实支付、生产消息队列、云告警发送和正式身份认证留给部署阶段接入。

## 影响

- 多客户隔离和成本计量先具备本地可验证的数据基础。
- 后续可把现有团队用户映射到正式账号体系。
- 不在本阶段保存支付凭证或实现真实扣费。
