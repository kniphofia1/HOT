# 研究员情报雷达：终局 Milestone 规划

## Summary

终局产品定位升级为：覆盖主流社交媒体的商业级 AI 情报中枢。

系统最终要把公开信号转化为可追溯、可聚类、可解释、可交付的情报工作流：

```text
多平台信源
-> RawItem 原始证据
-> EventCluster 聚合事件
-> 趋势判断与可解释评分
-> 商业简报与预警
-> 团队协作与 SaaS 化交付
```

路线不能从全平台抓取开始，而要按能力层推进：

```text
本地闭环 -> 稳定信源 -> 多平台事件聚合 -> 自动化采集
-> 团队协作 -> SaaS 化 -> 商业交付 -> Agent 情报官
```

## Milestone 0：v0.1 本地情报雷达

状态：completed

目标：证明核心闭环成立。

已具备能力：

- RSS、公开网页、Hacker News、GitHub、Reddit、Bluesky、Mastodon。
- `RawItem -> EventCluster -> Evidence -> hotScore -> Markdown Brief`。
- SQLite 本地持久化。
- 统一事件卡片。
- 可解释评分。
- Markdown 简报导出。

验收标准：

- 用户能从可信信源生成可追溯事件流和 Markdown 简报。

## Milestone 1：本地稳定版

目标：把当前版本做成每天可用的个人工作台。

关键功能：

- 信源健康检查。
- 失败重试与限流。
- 去重质量优化。
- 事件详情页增强。
- 简报模板可编辑。
- 数据备份与恢复。
- 本地凭证安全存储。

验收标准：

- 重启后数据稳定保留。
- 刷新失败不会拖垮全局流程。
- 每个事件都能回到原始证据。

## Milestone 2：信源市场与平台能力矩阵

目标：让用户清楚知道每个平台能接入到什么程度。

关键功能：

- 信源市场页面。
- 平台分级：官方 API、授权 API、Bot/Webhook、公开网页、人工链接补录、暂不支持。
- 每个平台展示成本、限制、是否需审核、是否需授权、是否支持指标。
- 手动链接补录入口。
- 受限平台只展示说明，不偷偷抓取。

验收标准：

- 用户能理解为什么某些平台可以自动化，某些平台只能补录。
- 新增信源不再是技术表单，而是产品化配置流程。

## Milestone 3：主流国际平台自动化

目标：覆盖国际主流公开讨论场。

优先接入：

- X：官方付费 API。
- YouTube：官方 Data API。
- LinkedIn：官方审核 API。
- TikTok：Research API 或官方授权能力。
- Telegram：Bot 加入频道后的授权读取。
- Discord：Bot 加入服务器后的授权读取。
- Slack：Workspace 授权读取。

验收标准：

- 每个平台都有独立 `Connector`、`FetchRun`、`MetricSnapshot`。
- 失败、限流、配额耗尽都有明确降级。
- 不使用 Cookie、登录态、验证码绕过。

## Milestone 4：国内平台合规接入

目标：覆盖中文互联网主流信号，但只走官方或用户授权路径。

平台范围：

- 微博。
- B站。
- 知乎。
- 微信公众号。
- 小红书。
- 抖音。
- 快手。

接入方式：

- 官方开放平台优先。
- 自有账号授权数据其次。
- 公开网页监控作为低能力模式。
- 人工链接补录作为兜底。
- 不做登录态抓取、Cookie 抓取、私有内容抓取。

验收标准：

- 每个平台都有清晰合规边界。
- 不能自动获取的内容，产品上明确标记为需人工补录或需官方授权。

## Milestone 5：事件智能层 2.0

目标：从信息聚合升级为趋势判断。

关键功能：

- 跨平台事件合并。
- 事件生命周期：首次出现、扩散、峰值、衰退。
- 事件可信度评分。
- 传播速度评分。
- 影响领域识别。
- 公司、人物、产品、技术实体抽取。
- 相似历史事件召回。

验收标准：

- 用户看到的是事件，而不是文章列表。
- 同一事件能显示另有多少个平台报道或讨论。
- 推荐理由能解释为什么现在值得关注。

## Milestone 6：商业简报与交付中心

目标：把情报变成可交付成果。

关键功能：

- AI 技术日报。
- 投资观察。
- 公司竞争情报。
- 行业周报。
- 风险预警。
- 项目尽调材料。
- Markdown / Word / PDF。
- 邮件、飞书、Notion、Slack 推送。

验收标准：

- 用户能从事件流一键生成可交付简报。
- 每条判断都保留来源引用。
- 输出格式适合真实汇报场景。

## Milestone 7：团队协作版

目标：从个人工具升级为小团队情报室。

关键功能：

- 用户账号。
- 团队空间。
- 共享信源。
- 事件收藏。
- 人工标注。
- 简报协作编辑。
- 审核流。
- 操作日志。

验收标准：

- 团队可以共同维护信源和简报。
- 每个判断能看到是谁标注、谁确认、谁导出。

## Milestone 8：SaaS 商业化版

目标：正式成为商业舆情与情报 SaaS。

关键功能：

- 多租户。
- 组织管理。
- 角色权限。
- 套餐计费。
- API 配额。
- 信源配额。
- 任务队列。
- 监控告警。
- 审计日志。
- 数据隔离。

验收标准：

- 多个客户可以安全共用同一套系统。
- 平台成本、抓取频率、AI 调用成本都可计量。

## Milestone 9：自动 Agent 情报官

目标：从用户查情报升级为系统主动发现并提醒。

关键功能：

- 主题 Agent。
- 公司 Agent。
- 竞品 Agent。
- 投资赛道 Agent。
- 风险 Agent。
- 异常扩散检测。
- 自动生成预警。
- 自动建议跟进问题。

验收标准：

- 用户不用每天手动刷新。
- 系统能主动指出异常事件并建议关注原因。

## Assumptions

- 尽量全自动限定在官方 API、公开协议、用户授权、Bot/Webhook 和公开网页监控范围内。
- Cookie 抓取、登录态模拟、验证码绕过、私有页面抓取不纳入路线。
- 当前 v0.1 规则仍然有效；进入 X、国内平台、YouTube、Word/PDF、多租户前，需要先更新产品文档和 ADR。
- 终局目标是商业 SaaS，但近期最优先的不是堆平台，而是把 Milestone 1-3 做稳。
