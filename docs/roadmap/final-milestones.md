# 研究员情报雷达：终局 Milestone 规划

## Summary

终局产品定位升级为：覆盖主流社交媒体的商业级 AI 情报中枢。

系统最终要把公开信号转化为可追溯、可聚类、可解释、可交付的情报工作流：

```text
多平台信源
-> RawItem 原始证据
-> EventCluster 聚合事件
-> 趋势判断与可解释评分
-> 商业简报与预警
-> 团队协作与 SaaS 化交付
```

路线不能从全平台抓取开始，而要按能力层推进：

```text
本地闭环 -> 稳定信源 -> 多平台事件聚合 -> 自动化采集
-> 团队协作 -> SaaS 化 -> 商业交付 -> Agent 情报官
```

## Milestone 0：v0.1 本地情报雷达

状态：completed

目标：证明核心闭环成立。

已具备能力：

- RSS、公开网页、Hacker News、GitHub、Reddit、Bluesky、Mastodon。
- `RawItem -> EventCluster -> Evidence -> hotScore -> Markdown Brief`。
- SQLite 本地持久化。
- 统一事件卡片。
- 可解释评分。
- Markdown 简报导出。

验收标准：

- 用户能从可信信源生成可追溯事件流和 Markdown 简报。

## Milestone 2：信源市场与平台能力矩阵

状态：completed

目标：让用户清楚知道每个平台能接入到什么程度。

关键功能：

- [x] 信源市场页面。
- [x] 平台分级：官方 API、授权 API、Bot/Webhook、公开网页、人工链接补录、暂不支持。
- [x] 每个平台展示成本、限制、是否需审核、是否需授权、是否支持指标。
- [x] 手动链接补录入口。
- [x] 受限平台只展示说明，不偷偷抓取。

验收标准：

- [x] 用户能理解为什么某些平台可以自动化，某些平台只能补录。
- [x] 新增信源不再是技术表单，而是产品化配置流程。

## Milestone 3：主流国际平台自动化

状态：completed

目标：覆盖国际主流公开讨论场。

优先接入：

- [x] X：官方付费 API。
- [x] YouTube：官方 Data API。
- [x] LinkedIn：官方审核 API。
- [x] TikTok：Research API 或官方授权能力。
- [x] Telegram：Bot 加入频道后的授权读取。
- [x] Discord：Bot 加入服务器后的授权读取。
- [x] Slack：Workspace 授权读取。

验收标准：

- [x] 每个平台都有独立 `Connector`、`FetchRun`、`MetricSnapshot`。
- [x] 失败、限流、配额耗尽都有明确降级。
- [x] 不使用 Cookie、登录态、验证码绕过。

状态：completed

目标：覆盖中文互联网主流信号，但只走官方或用户授权路径。

平台范围：

- [x] 微博。
- [x] B站。
- [x] 知乎。
- [x] 微信公众号。
- [x] 小红书。
- [x] 抖音。
- [x] 快手。

接入方式：

- [x] 官方开放平台优先。
- [x] 自有账号授权数据其次。
- [x] 公开网页监控作为低能力模式。
- [x] 人工链接补录作为兜底。
- [x] 不做登录态抓取、Cookie 抓取、私有内容抓取。

验收标准：

- [x] 每个平台都有清晰合规边界。
- [x] 不能自动获取的内容，产品上明确标记为需人工补录或需官方授权。

## Assumptions

- 尽量全自动限定在官方 API、公开协议、用户授权、Bot/Webhook 和公开网页监控范围内。
- Cookie 抓取、登录态模拟、验证码绕过、私有页面抓取不纳入路线。
- 当前 v0.1 规则仍然有效；进入 X、国内平台、YouTube、Word/PDF、多租户前，需要先更新产品文档和 ADR。
- 终局目标是商业 SaaS，但近期最优先的不是堆平台，而是把 Milestone 1-3 做稳。
